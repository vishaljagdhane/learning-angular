Angular Array Data Type With Methods

What is an Array?

An Array is used to store multiple values in a single variable.

colors: string[] = ['Red', 'Green', 'Blue'];

Output: {{ colors }}

1. push()

Adds one or more elements to the end of an array.

colors.push('Yellow');

Result: ['Red', 'Green', 'Blue', 'Yellow']

2. pop()

Removes the last element from an array.

colors.pop();

Result: ['Red', 'Green']

3. shift()

Removes the first element from an array.

colors.shift();

Result: ['Green', 'Blue']

4. unshift()

Adds elements at the beginning of an array.

colors.unshift('Black');

Result: ['Black', 'Red', 'Green', 'Blue']

5. splice()

Adds or removes elements from any position.

colors.splice(1, 1);

Result: ['Red', 'Blue']

6. map()

Creates a new array by transforming each element.

numbers.map(num => num * 2);

Result: [2, 4, 6, 8]

7. filter()

Creates a new array with elements that match a condition.

numbers.filter(num => num > 2);

Result: [3, 4]

8. length

Returns the total number of elements in an array.

colors.length;

Result: 3
