Practical Example: Using *ngIf

The *ngIf directive is used to show or hide HTML elements based on a condition.

First, declare a Boolean variable in the component's TypeScript file: 

ngifCondition = false;

By default, the value is false, so the element will not be displayed. When the value changes to true, Angular renders the element in the DOM.

Practical Example: Using @if (Angular 17+) with TypeScript Logic

In real-world Angular applications, business logic and conditions are usually written in the TypeScript (.ts) file rather than directly in the HTML template.

The component handles all decision-making using if, else if, and else statements, while the HTML template is responsible only for displaying the result.

This approach improves code readability, maintainability, and follows Angular best practices by separating business logic from the user interface.

Example Scenario

A user's login status is checked in the TypeScript file. Based on the result, a message such as "Welcome User" or "Please Login" is displayed on the screen.

Similarly, conditions can be used to calculate grades, control permissions, validate forms, manage user roles, and show or hide application features.

Benefits of Writing Conditions in TypeScript

  • ✔ Cleaner HTML templates
  • ✔ Easier debugging and maintenance
  • ✔ Better separation of concerns
  • ✔ Reusable business logic
  • ✔ Industry-standard Angular development practice
