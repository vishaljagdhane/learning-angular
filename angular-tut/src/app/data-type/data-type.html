String Data Type

A string is a sequence of characters, typically used to represent text.

Declare a string variable in the component file:

name: string = 'Vishal';

To display the value in HTML:

{{ name }}

Output: {{ name }}

Number Data Type

A number is a numeric value, typically used to represent integers or decimals.

Declare a number variable in the component file:

age: number = 30 ;

To display the value in HTML:

{{ age }}

Output: {{ age }}

Boolean Data Type

A boolean is a logical value that can be either true or false.

Declare a boolean variable in the component file:

isLoggedIn: boolean = true;

To display the value in HTML:

{{ isLoggedIn }}

Output: {{ isLoggedIn }}
