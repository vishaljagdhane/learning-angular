Practical Example: Angular Routing

Angular Routing enables navigation between different components without reloading the entire page. In this example, users can move between Home, About, Contact, and Login pages using RouterLink and view the selected component inside the RouterOutlet.

ROUTING CONCEPT DESCRIPTION HOW TO WRITE UI EXAMPLE REAL EXAMPLE
RouterLink Used to navigate from one page to another. <a routerLink="/home">Home</a> Navigate to Home, About, Contact, and Login pages.
RouterOutlet Displays the component associated with the current route. <router-outlet></router-outlet> Loads the selected page dynamically.
Default Route Redirects users to a default page when the application loads. path: '', component: HomeComponent Open Home page automatically.
Route Parameter Pass dynamic values through the URL. path: 'user/:id' Employee Details Page using Employee ID.
Programmatic Navigation Navigate using TypeScript code. this.router.navigate(['/home']); Redirect after successful login.
Child Route Create nested routes inside a parent route. children: [] Dashboard → Users → Profile.
Wildcard Route Handles invalid URLs and displays a 404 page. path: '**' Show Page Not Found screen.
Route Guard Restricts access to protected routes. canActivate: [AuthGuard] Allow access only after login.
Lazy Loading Loads modules only when required. loadChildren(...) Improve application performance.
