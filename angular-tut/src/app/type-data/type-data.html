Angular Data Types

Following data types are used in Angular: String , Number, Boolean, Array, Object

Data Type Description Example Using app.tsx file
String A sequence of characters enclosed in single or double quotes. name:String ="Hello Angular" {{name}}
Number A numeric value that can be an integer or a floating-point number. age: number = 25; {{age}}
Boolean A logical value that can be either true or false. isAngularFun: boolean = true; {{isAngularFun}}
Array A collection of values stored in a single variable, accessed by index. fruits: string[] = ['Apple', 'Banana', 'Orange'];
  • {{ fruit }}
Object A collection of key-value pairs, where each key is a string and the value can be any data type. person: { name: string; age: number; } = { name: 'John', age: 30 }; {{person.name}} is {{person.age}} years old.
